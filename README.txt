God’s Story — web app
====================

Upload everything in this folder to your web server (for example to /ucm/gods-story/).
Open index.html in a browser to use it. On iPhone or iPad, tap Share → Add to Home Screen to install it like an app.

index.html             The whole app (pages, styles and scripts in one file)
audio/                 Verse recordings played by the Listen buttons
pdf/                   The printable PDF offered by “Download PDF”
icons/                 App icon, browser icon and iPhone/iPad launch screens
manifest.webmanifest   Lets phones install the app
sw.js                  Lets the app open offline after the first visit (works on https only)

The “Copy link” buttons point to https://agtarapcreative.com/ucm/gods-story/. If you upload it somewhere else, change SITE_URL near the top of the app script in index.html.
